# 🏦 NOVA - AI Mortgage Intelligence Platform

## Overview

NOVA is an end-to-end Data Science project that predicts mortgage approval using Machine Learning.

The system analyzes applicant financial information and estimates:

- Approval Probability
- Decline Risk
- Monthly Mortgage Payment
- Loan Statistics
- Banking Risk Indicators

---

## Features

✔ Machine Learning prediction

✔ Mortgage payment estimation

✔ Banking risk analysis

✔ Approval & decline probabilities

✔ Interactive Streamlit dashboard

✔ Professional Data Science interface
